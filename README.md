1. 开工前获取远端更新，切换到自己的工作分支，并将 `origin/main` 合入工作分支。
2. 在工作分支开发、自测并小步提交。推送后在组内共享待审查的提交、改动说明和自测结果。
3. 由至少一名其他组员在线下或组内沟通渠道审查，并在组内确认结果。若审查后修改代码，提交更新后再请组员复核。
4. 组内审查通过后，由组长使用 Git 将通过审查的版本合入 `main`，验证可运行后推送到远端。保留工作分支，开始下一项任务前再次同步 `main`。
