## 1. C 的 `API.md` 还要改两处

### 1.1 分析接口路径

错误写法：

```text
GET  /api/admin/analytics/module-hot
POST /api/admin/analytics/interpretation
```

以 D 的实现为准：

```text
GET  /api/admin/analytics/modules
GET  /api/admin/analytics/trend
GET  /api/admin/analytics/funnel
GET  /api/admin/analytics/summary
POST /api/admin/analytics/interpret
GET  /api/admin/analytics/insights/latest
```

字段与返回示例见 [`docs/04-API.md`](04-API.md) 第 7 节。

### 1.2 活动创建字段

错误写法是 `start_at` / `end_at` 这类下划线字段，而且没有报名时间窗。以 D 的实现为准，创建活动必须传：

```json
{
  "title": "周末骑行活动",
  "subtitle": "可选",
  "cover": "可选，封面 URL",
  "description": "可选",
  "location": "可选",
  "startAt": "2026-11-28T01:00:00.000Z",
  "endAt": "2026-11-28T10:00:00.000Z",
  "signupStartAt": "2026-11-25T00:00:00.000Z",
  "signupEndAt": "2026-11-27T10:00:00.000Z",
  "quota": 50,
  "status": "draft"
}
```

约束：

- 全部时间用 UTC ISO，字段名是 camelCase；
- `endAt > startAt`；
- `signupEndAt > signupStartAt`；
- `signupEndAt <= endAt`；
- `quota` 为正整数；
- `status` 只允许 `draft` / `published` / `offline`；
- 活动状态不要套 C 的全局 `0/1` 规则。

## 2. B 的 `canInterpret()` 要收紧

B 的 `admin/js/api.js` 目前是：

```js
canInterpret: () => Perm.role() === 'super_admin' || Perm.role() === 'operator'
```

改为：

```js
canInterpret: () => Perm.role() === 'super_admin'
```

原因：D 已把 `analytics:interpret` 从 `operator` 权限中移除；operator 仍可看分析看板和已有解读，但不能发起 AI 解读。完整手机号 CSV 同理，`canExportPhone()` 保持仅 `super_admin`。
