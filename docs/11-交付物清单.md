## 5. 答辩 PPT 八页建议（本模块视角）

1. **项目与目标**：一句话——摩托车小程序 + 运营后台，4 人两周交付。
2. **需求与范围**：我负责登录、用户、活动、报名、分析；明确不做什么。
3. **方案与架构**：一张架构图（`docs/02` 的 Mermaid 可转图）+ 技术选型理由。
4. **数据与接口**：ER 图 + 30 个接口 + 统一信封 / 错误码。
5. **功能演示**：登录 → 活动发布 → 报名 → 防重 / 名额 → 统计导出。
6. **难点与取舍**：并发名额、严格顺序漏斗、SQLite vs MySQL、session vs user。
7. **AI 两个模块**：本模块的分析解读（Prompt / JSON / 兜底）；客服由同学讲。
8. **复盘与下一步**：技术债、真实埋点、MySQL、登录限流、活动维度漏斗。

> 第 8 页最容易被忽略也最容易加分：诚实说出短板，比硬夸功能齐全更可信。
